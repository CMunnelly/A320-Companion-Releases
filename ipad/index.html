Integrations

Enter your own details. SayIntentions is optional.

When no key is saved, Companion obtains it from your running SayIntentions client. Saved keys are protected by your Windows account. Keys are not displayed back to the browser.

ApronLife

Optional ground services for surrounding aircraft.

Install ApronLife separately. Companion tries to find it in Downloads or its usual installation folders. Enabling launches ApronLife and requests ground services; ApronLife handles simulator readiness. Disabling prevents future automatic launches. Use Stop below to stop current services.

Satellite maps

Google Maps satellite imagery. Requires your Google Maps JavaScript API key and a billing-enabled Google Cloud project.

The browser receives this map key to load Google Maps. Restrict it to the Maps JavaScript API and your Companion web addresses; set usage quotas in Google Cloud. Imagery needs internet access.
